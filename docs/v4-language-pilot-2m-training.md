## 实验复现流程

从仓库根目录运行。新的 Registry 和污染处置文件存放在本地。重新审计显示两条历史匹配仍是相同文档与同一无参考答案的英文前缀，复用对应人工决定后未处置高风险匹配为 0。五条自然续写、四条诊断前缀及固定参考后缀的组合在 Train、选中 Train、Val 和 Test 中均无完全重合。复现使用独立数据和报告目录。

```bash
PYTHON=.venv/bin/python
RUNNER=scripts/run_v4_language_2m.py

"$PYTHON" "$RUNNER" build --source-registry "$REVIEWED_2M_REGISTRY" \
  --contamination-decisions "$REVIEWED_CONTAMINATION_DECISIONS"
"$PYTHON" "$RUNNER" probe
"$PYTHON" "$RUNNER" execute
"$PYTHON" "$RUNNER" evaluate
```

新工作区可以使用 `run` 一次执行四个阶段。单次运行中的每次准入仍重新核验原始快照与样本 SHA256，同一清单的确定性采样只完整重放一次。恢复中途中断的训练请按下文单独运行相应阶段。

Build 复跑 V4 的 Ingest、Quality、Dedup、Split。新结果须通过隔离审计，并与已冻结历史 Train/Val/Test 的文档内容及分组逐条核对。权利范围由 2M Registry 单独绑定，原分割文件保留原始记录和字节。复用此前人工审核通过的 Tokenizer，重新编码后核对 Val/Test BIN 与 Token Index 字节级一致。新 Train 按原顺序规则选择整文档、保留 EOS，独立计算监督预算，再通过污染、编码、配额和冻结门禁。构建成功后须同时获得 `READY` 和 `POLICY_MATCH`。

训练继续使用 86,528,640 参数模型、原 Step 0 的 SHA256 `bfdd11421cb247d5b8c88b7b268f8f4353e0bc12c5fcfae49085929799cc3e99`、Seed 42、FP32、1×8 梯度累积和 1,024 序列。单一 AdamW 学习率计划跨 245 步，4 步 warmup，峰值 `3e-4`，最小 `3e-5`，余弦衰减，梯度裁剪 1.0。Step 0、123、245 各归档独立的权重、训练状态和哈希清单。完整评测从归档读取，独立于训练进程。训练器内已有的 Val 计算保留随机状态。

## 已实现的统一评测

- 固定原 1M Train 的 64 个代表性窗口，共 65,472 个监督位置，窗口索引 SHA256 为 `7004c202d0a058f9c905194155bdf563e379a09c04f3eb58b66b36b5b3c44e2c`。四个 FP32 节点和最终 INT4 使用同一套公共 Train，并使用原 Val 的全部 101 个完整窗口。逐位置计算总体及分类 Loss、PPL。原 Test 的 101 个完整窗口仅在预定的最终 FP32 节点使用一次。参考后缀提供 teacher-forced Loss、下一 Token 概率和排名。
- 每个节点运行原始 300 题、五条固定续写和四条诊断前缀。Greedy 和三种采样策略统一使用每题原预算。采样 Seed 为 42、43、44，重复惩罚固定为 1.0。保存每条文本、完整 Token ID、停止原因和退化指标。
- 保留原评分器和知识分类。人工评估尚待进行，103 项需要人工评分的题在每个配置中均标为 `PENDING`，并附上评估依据及通顺、连贯、相关、事实准确性和无意义重复等维度。
- 最终 Step 245 按 Group Size 128 导出 INT4，校验 50,000,000 字节上限。按相同提示和配置比较 FP32/INT4 的 Loss、Top-1、Top-20 与生成。INT4 权重以反量化 FP32 运行。
- 评测报告包含 `comparison.md`、配对窗口与配置、各节点文件身份、实际监督消费、每步 Loss/LR 曲线数据、逐条预测，以及 `fp32-int4.json`。原始语料、权重和运行报告保留在 Git 忽略目录。

## 实测结果

### Loss 与预测分布

同一训练内从 Step 123 到 245，公共 Train Loss 下降 **0.3322**，Val Loss 下降 **0.3074**。完整 Val 上四类 Loss 均下降。

| Val 类别 | 历史 Step 123 | 新 Step 0 | 新 Step 123 | 新 Step 245 |
|---|---:|---:|---:|---:|
| 中文通用 | 7.5249 | 10.2615 | 7.4398 | 6.9409 |
| 中文百科 | 8.1742 | 10.2548 | 8.1275 | 7.8247 |
| 中文教育 | 8.3316 | 10.2581 | 8.1369 | 7.9248 |
| 英文通用 | 7.4442 | 10.2182 | 7.3564 | 7.2398 |

九条固定前缀的首步平均标点概率由历史 1M 的 **12.18%** 降为 2M 的 **6.37%**，换行类概率分别为 **2.22%** 和 **1.94%**。标点或换行占据 Top-1 的前缀数由 9/9 降到 4/9。新 Step 123 和 245 的首步平均熵分别为 **8.062** 和 **8.508 nats**。四条带固定参考后缀的前缀，其逐条 Teacher-forced Loss 的均值从新 Step 123 的 **8.7377** 降至 **8.4005**。Step 245 的真实下一 Token 排名仍在第 **2,354 至 6,145** 位，逐条概率及排名保存在 `comparison.json`。

### 生成退化与知识评分

- 历史 PR #16 的 300 条 Greedy 逐题复现，提示与生成 Token、预算、停止 Token 和停止原因均一致。新 Step 123 的 300 条均只有空白、含汉字输出为 0，汉字字符占比因此没有分母。固定续写仍能出现 `月，月，月` 一类短循环。
- Step 245 的 300 条 Greedy 从全空白发展到 68 条含汉字。非空白字符中汉字占 20.75%、标点占 69.83%，空输出率 7.67%，字符 3-gram 重复率 88.40%，EOS 结束率 0%，未见异常或特殊 Token。五条自然续写仍受退化影响，例如 `zh-cont-01` 开头为 `在而，在在在在，在，，，，`，随后长串逗号。可观察到汉字和短片段，尚无稳定的连贯短句证据。
- Step 245 的常规、高温、Nucleus 采样在三个 Seed 上的平均 Token 4-gram 重复率分别为 0.19%、0.01%、0.02%，EOS 结束率为 27.78%、26.22%、13.89%。这些变化并未带来自动评分提升。所有节点、四种解码策略与相应 Seed 的成绩均为 0/197，其中地理历史 0/49、科学 0/48。概念、流畅度等人工项仍为 `PENDING`。目前没有基础世界知识改善的证据。

### FP32 与 INT4

Step 245 INT4 文件为 **44,730,534 字节**，低于 50,000,000 字节上限。SHA256 为 `21069ba0f93befe7377e649b0350a1ac32833f38400bacf807ec79d70e9c0e54`。相对 FP32，Train Loss 增加 0.0065，Val Loss 增加 0.0027。九条固定前缀的 Top-1 一致 8/9，Top-20 每条平均重叠 18.78，平均 logit RMSE 为 0.0837。

完整 Greedy Token 序列一致 115/309。常规、高温、Nucleus 采样分别一致 99/927、107/927、91/927。INT4 的 Greedy 标点字符比例为 74.53%，FP32 为 69.83%，两者都存在明显循环且自动评分均为 0/197。量化在文件大小和配对 Loss 上达标，具体输出对数值扰动较敏感，现有结果无法确认语言能力等价。推理使用反量化 FP32。

## 后续扩展判断

这次实验支持更多训练能降低配对 Loss，并提供 Greedy 有效字符开始恢复的有限证据。标点循环、连贯性和知识评分仍未达到能据此判断扩展收益的程度。Step 123 到 Step 245 共用一个学习率计划，期间学习率和已消费语料同时变化，因果解释限于本方案。

PR #17 在固定名义配额和现有容差下找到的最大打包预览为 2,610,696 个监督 Token。4M 的名义配额至少还缺 625,602 个中文通用监督 Token。补齐独立获批的库存后，4M 可作为下一次严格配对观测，优先完成人工评估以量化可读性与事实正确性。现有结果不足以支持直接扩到 10M。[PR #17 预算与范围核算](v4-language-degeneration-diagnostics.md#扩展库存与审批)
