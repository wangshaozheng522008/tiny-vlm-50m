第二阶段预算依据 [PR #21 的独立授权记录](../configs/v5-language-20m-repeat-authorization.json)，限该冻结内容的内部研究，新增 10,000,848、累计最多 20,001,696 个有效监督 Token。PR #19 的来源及冻结证据仍用于验证数据准入和来源配额，单轮入口仍执行禁止重复采样的门禁。

父状态为 `runs/v5-language-pilot-10m-v1/state.pt`，SHA256 为 `97529f5f1b4fe0e9a4a34c3b6ead1620f57ab6f2567d6dfdf9d503e108f325ea`。预检逐一比对最终模型、最终训练状态、Step 1222 模型和该里程碑恢复状态中的 147 个 FP32 张量，名称、形状、类型及数值一致。第二阶段继承这些权重、AdamW 一阶和二阶动量、每个参数的 1,222 次更新计数，以及 Python、NumPy、PyTorch 和 CUDA RNG。独立 Manifest 绑定父谱系、授权和实际 Sampler 重放。

Batch Size 为 1，序列长度为 1,024，梯度累积为 8，梯度检查点开启，使用 FP32。第二阶段调度器从阶段索引 0 开始，前 20 次更新线性 Warmup，峰值学习率为 0.00015，到最后一次更新余弦衰减至 0.00001。训练以阶段步数安排保存和验证，每 50 步保存滚动状态，每 100 步与每个里程碑跑完整 V5 Validation。验证损失连续三次超过此前最佳值的 103% 时记录警告，训练仍按固定计划运行。

## 复现与恢复

在仓库根目录运行以下命令。训练及恢复入口都重验授权、冻结数据、父状态与 Sampler，评测另行重验完成状态和报告身份。

```bash
.venv/bin/python scripts/run_v5_language_20m_repeat.py preflight
.venv/bin/python scripts/run_v5_language_20m_repeat.py execute
.venv/bin/python scripts/run_v5_language_20m_repeat.py evaluate
```

中断后使用 `execute --resume state.pt` 延续最后一条已持久化更新。主状态不可读时可显式选用 `execute --resume state.prev.pt`。回退会归档恢复点之后的日志，继续使用已承诺的窗口顺序及阶段学习率。各里程碑有独立模型、完整恢复状态和 SHA256 收据。最低 Validation Loss 对应的模型另存为 `best.pt`。

训练资产位于 `runs/v5-language-pilot-20m-repeat-v1`，前置核查、评测明细和曲线位于 `reports/v5-language-pilot-20m-repeat-v1`。二者均使用独立目录。

## 评测协议

复用 PR #20 固定的 300 道题、5 条续写、4 条下一 Token 诊断前缀，以及原有评分、96 Token 生成上限和逐题预算。6 个 FP32 节点全部执行 Greedy。10M 和 20M 的 FP32 及 INT4 另含标准采样、高温采样和 Nucleus，各用 Seed 42、43、44。10M 从经过一致性验证的历史报告中读取。

固定窗口损失包含 PR #20 的共同 Train/Val 与全量 V5 Val。另用 Seed 42 和同一代表性窗口算法从冻结 V5 Train 选定固定样本，作为复述和过拟合诊断的训练侧对照。Train/Val 差距以全量 V5 Val Loss 减该固定 V5 Train Loss 计算。模型选择按完整 V5 Validation 的损失完成。生成重合检查按冻结训练文档统计最长连续完全相同的内容 Token 片段，逐题保留至少 16 Token 的精确匹配，并另统计至少 32 Token 的结果。匹配窗口保持在单个训练文档内。

比较方案和选模结果发布后，可以对最终 20M FP32 运行一次 V5 Test，命令为 `evaluate --final-test`。V5 Test 在历史 10M 阶段已有评测记录。人工流畅度、完整性、相关性和事实判断状态为 `PENDING`。
