## 执行路径

在仓库根目录运行下列命令。探测先核验冻结、准入、来源、Tokenizer、初始权重、Sampler、显存和存储。训练入口复核探测结果及当前文件身份。训练目录为 `runs/v5-language-pilot-10m-v1`，报告保存在 `reports/v5-language-pilot-10m-v1`。

```bash
.venv/bin/python scripts/run_v5_language_10m.py probe
.venv/bin/python scripts/run_v5_language_10m.py execute
.venv/bin/python scripts/run_v5_language_10m.py evaluate
```

收到终止信号时，训练器保存当前完整优化器更新，恢复时通过 `execute --resume state.pt` 使用原状态。原状态损坏时可指定 `state.prev.pt`，启动器仍核对训练谱系、设置和进度。里程碑各自保留带文件 SHA256 的状态和模型。

## 训练量、语料和学习率

同一训练轨迹上，V5 Val Loss 由 10.2542 降至 6.1454，共同历史 Val Loss 由 10.2532 降至 7.0724。历史对照同时使用了不同的语料和学习率计划，同一轨迹内的学习率与采样位置也随更新变化，无法把差异单独归因于 Token 数量。

10M 相比历史 1M、2M 的含汉字概率和 EOS 率更高，标点循环显著减少。4M 的 Token 4-gram 重复率为 17.42%，到 10M 回升到 32.28%，说明 Loss 持续改善时，生成重复仍会波动。基础世界知识未突破零分。INT4 的平均损失接近 FP32，具体生成序列和重复表现仍有明显差异。

50M 值得作为独立验证实验，前提是补齐经过审批的独立窗口，并保留同一评测和中间里程碑来观察知识和续写。现有库存距离 50M、100M 分别缺 39,091、87,963 个独立窗口。10M 的续写和自动知识结果不足以支持直接扩大到 100M。
